# ⌨️ Горячие клавиши (Hotkeys) Weavify

Для максимального удобства управления музыкой в Weavify реализована поддержка глобальных медиа-клавиш и локальных сочетаний:

| Сочетание / Клавиша | Действие |
|---|---|
| `Space` / `MediaPlayPause` | Воспроизведение / Пауза |
| `Ctrl + Right` / `MediaNext` | Следующий трек |
| `Ctrl + Left` / `MediaPrev` | Предыдущий трек |
| `Ctrl + Up` | Увеличить громкость (+5%) |
| `Ctrl + Down` | Уменьшить громкость (-5%) |
| `Ctrl + M` | Включить / Выключить звук (Mute) |
| `Ctrl + F` | Фокус на строке глобального поиска |
| `Ctrl + L` | Открыть полноэкранный режим текста песни (Lyrics) |
| `Ctrl + W` | Свернуть окно в системный трей |
| `Ctrl + Q` | Полный выход из приложения |
