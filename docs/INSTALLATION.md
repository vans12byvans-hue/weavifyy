# 🚀 Руководство по установке Weavify

### 📋 Системные требования
- **Операционная система**: Windows 10 (версия 1809+) / Windows 11 (64-bit)
- **Процессор**: 1.6 ГГц или выше (x86_64)
- **Оперативная память**: от 2 ГБ ОЗУ (рекомендуется 4 ГБ)
- **Свободное место на диске**: ~250 МБ
- **Среда выполнения**: Microsoft Edge WebView2 (по умолчанию предустановлена в современных версиях Windows 10 и 11)

---

### 💾 Установка на Windows

1. Перейдите в раздел [Releases](https://github.com/vans12byvans-hue/weavifyy/releases/latest).
2. Скачайте официальный установщик: `Weavify_8.2.1_x64-setup.exe`.
3. Запустите файл `Weavify_8.2.1_x64-setup.exe`.
4. Следуйте простым указаниям мастера установки:
   - Выберите директорию установки (по умолчанию `%LOCALAPPDATA%\Programs\Weavify`).
   - Создайте ярлык на рабочем столе и в меню «Пуск».
5. После завершения установки приложение запустится автоматически.

> [!NOTE]
> При первом запуске Windows SmartScreen может отобразить предупреждение о неопознанном издателе. Нажмите **«Подробнее»** (More info) → **«Выполнить в любом случае»** (Run anyway).

---

### 🔄 Автоматическое обновление

Weavify оснащен встроенным модулем автообновления:
- При запуске плеер автоматически сверяет текущую версию с GitHub Releases.
- При появлении новой версии появится уведомление с предложением обновиться.
- Обновление скачивается и применяется в один клик без потери пользовательских данных и плейлистов.
