# 📜 Журнал изменений (Changelog) Weavify

Все заметные изменения проекта документируются в этом файле в соответствии с принципами [Semantic Versioning](https://semver.org/).

---

## [8.2.1] — 2026-09-27

### ⚡ Производительность и оптимизация
- **Оптимизация движка**: Снижено потребление оперативной памяти до рекордно низких показателей благодаря переходу на ядро Tauri 2.11.
- **Стабильность буферизации**: Устранены задержки при переключении треков в режиме «Моя волна».
- **Синхронизация текстов**: Повышена точность привязки таймкодов караоке-текстов песен в полноэкранном режиме.

### 🐛 Исправления ошибок
- Исправлено позиционирование контекстных меню и оверлеев в компактном миниплеере.
- Устранена утечка памяти при длительном непрерывном воспроизведении через Web Audio API.
- Оптимизирована фоновая проверка обновлений через GitHub Releases API.

---

## [8.2.0] — 2026-07-26

### 🚀 Нововведения и исправления
- Встроенный сервер бэкенда упакован непосредственно в приложение с автоматической инициализацией зависимостей.
- Исправлена видимость модального окна «Поделиться».
- Загрузка аватаров со страницы артиста из локальной базы данных и оперативной памяти.
- Кнопки добавления трека в избранное теперь корректно сохраняют обложки в локальное хранилище.
- Исправлено наложение кнопок боковой панели на миниплеер.
- Интегрирована цифровая подпись релизов Tauri Updater.

- Обновление системы безопасности и обфускации.
